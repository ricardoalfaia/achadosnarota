O **Meuproduto** ajuda pequenos escritórios a criar, organizar e acompanhar seus documentos. A ideia é trocar o modelo de Word copiado e alterado à mão por modelos com campos preenchidos a partir do cadastro do cliente, com histórico de versões e de assinaturas.

<Callout type="warn" title="Em construção">
  O Meuproduto está em desenvolvimento. Esta documentação descreve só o que já
  existe; as áreas que ainda não estão prontas aparecem como em construção.
</Callout>

## Para quem é

- **Administrador do escritório:** cuida da equipe, dos modelos e das permissões.
- **Operador ou secretária:** cadastra clientes, preenche documentos e acompanha o andamento.

## Como seus dados são tratados

- Documentos e dados de clientes são tratados como confidenciais.
- Cada escritório só vê os próprios dados.
- Um documento assinado não é alterado: uma mudança gera uma nova versão.

## Como usar

- **Buscar:** use o campo de busca no topo, ou o atalho `Ctrl K`, para encontrar uma página pelo assunto.
- **Idioma:** a documentação está em português e inglês. Troque pelo seletor de idioma do menu.
- **Tema:** escolha entre claro, escuro ou o tema do seu sistema operacional.
