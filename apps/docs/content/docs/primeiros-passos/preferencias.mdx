No **menu do usuário**, aberto pelo seu avatar no canto superior direito, você escolhe como o sistema aparece para você.

## Tema

| Opção  | O que faz                                    |
| ------ | -------------------------------------------- |
| Claro  | Fundo claro.                                 |
| Escuro | Fundo escuro.                                |
| Auto   | Acompanha o tema do seu sistema operacional. |

## Idioma

O sistema está disponível em **Português (Brasil)** e **English**. O idioma vale para os menus e as telas do sistema.

<Callout title="Onde ficam as preferências">
  As preferências ficam guardadas no navegador. Em outro navegador ou
  computador, escolha de novo.
</Callout>
